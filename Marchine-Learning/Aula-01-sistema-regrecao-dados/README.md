# 💰 Previsão de Salários com Machine Learning

Este projeto utiliza **Machine Learning** com **Regressão Linear** para prever o salário de um funcionário com base em informações profissionais. O modelo foi desenvolvido em um **Jupyter Notebook** e disponibilizado em uma interface gráfica criada com **Streamlit**.

## 🚀 Tecnologias

- Python
- Pandas
- Scikit-Learn
- Joblib
- Streamlit
- Jupyter Notebook

## ▶ Como executar

1. Instale as dependências:

```bash
pip install jupyter notebook pandas scikit-learn joblib streamlit
```

2. Execute o notebook para gerar o modelo (`preditor-salarios.pkl`).

3. Inicie a interface gráfica:

```bash
streamlit run app.py
```

## 📌 Importante

Para testar este projeto corretamente, **abra apenas a pasta `AULA-01`** no VS Code. Ela contém todos os arquivos necessários para o funcionamento do notebook e da interface gráfica.
